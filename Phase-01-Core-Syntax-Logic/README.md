# Phase 1: Core Computational Logic & Syntax 💻

## 🎯 The Objective
The goal of this phase is to master the baseline rules of procedural execution. Before building complex interfaces or handling large data structures, a computer scientist must understand how a computer stores basic information in memory, manipulates text and numbers, and uses conditional code blocks to make logical decisions.

## 🗝️ Core Mastery Targets

### 1. Primitive Memory Allocation
Understanding how the JavaScript engine handles baseline data types like numbers and text strings. This includes learning how to perform mathematical operations safely and how to use modern string manipulation (like template literals) to format clean outputs.

### 2. State & Scoping (Variables)
Learning how to use variables (`let`, `const`, and `var`) to store data values that can change or remain constant. This introduces the concept of global vs. local block scoping—ensuring data is only accessible where it is architecturally supposed to be.

### 3. Control-Flow Execution
Mastering Boolean values (`true` / `false`) and conditional statements (`if`, `else if`, `else`) to build decision-making logic. This allows the program to run different blocks of code depending on user inputs or system states.

### 4. Functional Encapsulation
Transitioning away from long, repetitive scripts by wrapping step-by-step procedures inside reusable functions. This establishes the habit of writing clean, modular code that accepts parameters (inputs) and yields returns (outputs).
