## 3. forEach()
For each is a method from the array class
it takes 2 params : 1st = value & 2nd = index
/!\ Order is important : 

```javascript
[
  'make dinner',
  'wash dishes',
  'watch youtube'
].forEach(function(value, index) {
  console.log(index);
  console.log(value);
})
```
